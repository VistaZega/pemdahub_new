# UI UX Pro Max Skill

This skill provides comprehensive UI/UX design intelligence, design system generation, color palette selection, font pairing, typography, animation guidelines, and UX best practices.

## Overview & Core Capabilities

1. **Design System Generation**: Reasoning engine for generating tailored color schemes, typography, layout density, and interactive components.
2. **Search Engine & Guidelines**:
   - `style`: UI styles (Glassmorphism, Soft UI, Minimalist, Neumorphism, Dark Mode, High Contrast, etc.).
   - `color`: Curated harmonious color palettes.
   - `typography`: Font pairings (Google Fonts).
   - `landing`: High-converting landing page layouts and hero section patterns.
   - `chart`: Data visualization guidelines.
   - `ux`: Best practices & anti-patterns.
3. **Usage**:
   - When building web applications, landing pages, dashboards, or UI components, consult the design principles in `data/` and `src/` to ensure visual excellence.

## Main Rules & Principles

- **No Generic Aesthetics**: Always use vibrant, modern, tailored color palettes instead of standard plain red/blue/green.
- **Modern Typography**: Use Google Fonts pairings (e.g. Inter, Outfit, Roboto, Plus Jakarta Sans, Montserrat).
- **Responsive & Dynamic**: Micro-interactions, smooth hover transitions, clear visual hierarchy, and 100% text contrast.
